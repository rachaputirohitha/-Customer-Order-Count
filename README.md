 # Task 20 – Customer Order Count

## Objective
The objective of this task was to count orders per customer and identify frequent buyers using Excel.

## Dataset
The analysis was performed using the Sample Superstore dataset.

Important columns used:
- Customer ID
- Order ID

## Methodology
1. Created a working table containing Customer ID and Order ID.
2. Removed duplicate Customer ID + Order ID combinations to avoid counting repeated order lines.
3. Created a PivotTable.
4. Added Customer ID to Rows.
5. Added Order ID to Values and used Count.
6. Sorted customers from highest to lowest order count.
7. Identified the Top 10 customers.
8. Created a bar chart to visualize the Top 10 customers.

## Key Findings
- Customer order frequency was calculated using a PivotTable.
- Duplicate order lines were removed before counting orders.
- Customers were sorted based on order count.
- The Top 10 customers were identified.
- A bar chart was created to visualize customer order frequency.
- The analysis helps identify customers who place orders frequently.

## Visualization
### Top 10 Customers by Order Count
A bar chart was created with:
- X-axis: Number of Orders
- Y-axis: Customer ID

## Skills Used
- Microsoft Excel
- Data Cleaning
- Remove Duplicates
- PivotTables
- Sorting and Filtering
- Data Analysis
- Data Visualization

## Conclusion
This task provided practical experience in analyzing customer ordering behavior. The customer-level order count makes it easier to identify frequent buyers from transaction-level data.
